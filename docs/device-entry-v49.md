# 由已有连接的设备生成私人直达链接

## 使用

结束当前学习并刷新仍能云同步的手机或电脑，打开「云同步」，点「连接新设备（生成直达链接）」。网页使用已有登录会话，不发送邮件，不要求输入或设置密码。成功后显示完整私人网址并尝试复制；不支持自动复制时，可点击「复制直达链接」或长按网址复制。

将该网址在 Edge 或自己的另一台设备打开，网页自动连接同一份词库。入口存在目标设备的独立浏览器存储中，之后通常不必再打开完整链接。清除网站数据或换设备后，需重新使用原链接。该网址允许读写词库，只应交给自己的设备；它不是可以公开分享的普通网址。

若所有设备都已退出或原会话被服务端撤销，不能凭空识别本人，此入口不能代替账号恢复。没有仍然有效的原会话时，按钮不会创建权限，也不会声称成功。

## 权限与数据

真实随机值只在用户点击按钮后的浏览器里生成，使用 Web Crypto 的 32 字节随机数。登记请求使用既有 Supabase access token，通过正常 authenticated 权限，且只上传随机值的 SHA-256 摘要。服务端检查 auth.uid、authenticated 角色、已签名 JWT 中的本人邮箱及该人的现有学习记录；不接受客户端指定用户 ID。

登记和停用函数不允许 anon 或 public 执行。密钥表的 RLS 和禁止直接访问的授权保持不变。普通词库也没有开放给匿名用户。服务端从摘要查找对应的原用户，读写仍沿用 revision 比较、事务锁和前端合并保护。

生成入口不改密码、不创建账号、不覆盖词库。浏览器单独保存待登记/已登记入口，不写入学习 JSON 备份。请求中断后重复点击会重试同一摘要，不会每次产生一条孤立入口。每个账号最多 20 条有效入口。「入口管理 → 停用这条链接」只撤销该入口，不删学习数据。登出只忘记本设备保存的生成记录，不撤销其他设备。

## 验证范围

单元测试使用模拟认证和登记服务器，覆盖正确会话、错误账号、登录失效、网络中断、摘要请求、响应校验、重复操作、页面重开及停用。JSDOM 测试覆盖实际云同步窗口上的按钮、文本框、复制降级，以及入口显示期间禁止自动覆盖页面。

生产仅部署函数定义与授权。没有通过管理工具创建任何真实私人入口，也没有读取或导出用户的会话凭证。真实入口须由用户现有已连接设备按按钮创建。本次不能宣称已在用户实体 Edge 或 iPhone 上完成真实登录验证。
