# 每日与每本词书错词复习（v45）

## 使用

首页「错词复习」或底部「错词」进入清单。选择今天、昨天、上次错词、近 7 天、全部历史，或指定开始/结束日期；再按所属词书、错误来源、最近状态和中英文关键词筛选。首次进入优先显示今天以前最近一次有错词的日期；之后记住本机的筛选和勾选。

每行显示英文、当前中文、错误日期、当天错误次数、所属词书、能够确定时的当时练习词书、模式、最近判断和当天错误明细。书籍和日期汇总可点击筛选。新拼写复习的错误输入会保留并展示。提供筛选结果 CSV 导出。

可逐词勾选、全选某天或全选筛选结果；选择跨日期按原单词 ID 去重，切换筛选不丢选择。一个原词条属于多本书只复习一次；已经存在的不同 ID 不强行合并。退休/简单词仍可手动选择复习，不改变其状态。

「听音复习已选」播放英文，再由用户判断熟悉/不熟悉；「拼写复习已选」播放英文，输入英文单词或短语并自动判定。答案揭晓后可以纠正误判。跳过不计错误。一轮结束显示答对、仍错、跳过，可再次练本轮错词。即使当天已答对，也允许再次选择练习。

## 历史口径

当天实际错过，之后答对仍保留在原日期清单里；「最近已答对」仅表示该词相关题型的最新结果正确，不表示永久掌握。听音、中文手打、英文拼写分开判断，听音答对不会替代拼写或中文手打结果。主动纠正误点修改的是那次判断，而不是伪造一条新作答。

新判断保存当时全部词书归属及能够确定的练习词书。旧正式记录没有归属快照时，按当前词库补充并明确标注。一个词可以有多个归属，因此各本小计可能重叠，顶部总词数按 ID 去重。绿色特别注意作为附加归属保留。模式和词书筛选的错误次数只计算符合条件的错误事件，而不是整个词的所有错误。

已有正式听词和中文手打事件可以回溯整理。旧版自由听只在当轮内存保留不熟词，没有落盘的历史不能恢复；新版从加载之后开始记录每次自由听判断。此页面统计独立词库，不混入整句听写或数据图练习。没有当时逐次保存的错误拼写，不编造出来。

## 数据与边界

自由听和错词复习写入独立的 `vocabPracticeEvents`，不进入排程用的 `events`，不修改 FSRS 卡片、不占或扩充今日新词/复习配额。原单词 ID、中文、词书、卡片及既有历史不被重置。新练习日志随 JSON 备份与云同步保存，云合并按事件 ID 保留两端新增记录。

筛选与勾选只记在本机 localStorage；已提交的每次作答立即进入保存队列。刷新保留筛选和勾选，但不会恢复未提交输入或一轮中的当前位置。存在勾选或正在复习时，自动云端应用会等待，不在操作中途整页替换。

本次不需要 Supabase 表结构变更，也没有将上传的私人词表写入公开仓库。

## 更新

结束当前学习，导出本机备份，在原来浏览器或主屏幕 App 刷新加载新版。不要清空网站数据、删除词库或用云端整份覆盖来安装此功能。多设备使用时，每台设备都应加载新版后再继续同步。
